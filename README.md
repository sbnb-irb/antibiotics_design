# antibiotics_design
Code and resources for species-conditioned generation of small-molecule antibiotics using text-derived bacterial descriptors and latent diffusion.

The data and models necessary to reproduce the results are stored in Zenodo at: https://zenodo.org/records/23039134

DOI: 10.5281/zenodo.23039134.

It is necessary to copy both uncompressed folders inside the repository directory to reproduce the results.
